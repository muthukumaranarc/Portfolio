# Project Screens

Upload screenshots here to show them in the animated project showcase.

- Put desktop/laptop screenshots in `desktop`.
- Put Android/mobile screenshots in `mobile`.
- Use the same filename for matching desktop and mobile screenshots, for example:
  - `desktop/portfolio.webp`
  - `mobile/portfolio.webp`

Recommended format: `webp` (smallest, fastest). `png`, `jpg`, and `jpeg` are also supported.
