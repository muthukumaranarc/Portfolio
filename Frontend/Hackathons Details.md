## 2. Chameleon

**Year:** 2026  
**Event:** Google Developer Group (GDG) × KSRCE Hackathon  
**Status:** Project Built

### Overview

Developed **Chameleon**, an AI-powered machine troubleshooting solution designed to analyze multiple types of information and assist in identifying machine problems.

The system explores multimodal inputs such as **images, videos, text, and voice**, while also considering machine-specific information. These inputs are processed through an AI-driven workflow to identify possible root causes, determine the affected machine component, and generate structured troubleshooting guidance.

### My Role

- Full-stack development
- Backend development
- AI workflow design
- Multimodal input integration
- REST API development
- System architecture
- Technical integration

### Technologies

- React
- Spring Boot
- AI / LLM
- Multimodal AI
- REST APIs
- Docker

### Key Focus

- Multimodal problem analysis
- AI-assisted troubleshooting
- Machine-specific knowledge
- Root-cause identification
- Structured solution generation
